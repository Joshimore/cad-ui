# CAD UI — Command & Agent Dashboard

Локальная веб-обёртка над любой рабочей папкой: дерево файлов, markdown-вьюер, недавние, избранное. Строго локально: сервер слушает только `127.0.0.1`, никаких API-ключей и внешних вызовов.

Это фаза 1 (ядро: файловый слой). План проекта: `ENVIRONMENT/PROJECTS/clients/03-cad-ui/`.

## Установка

Нужен Python 3.11+ (с pip).

```
git clone <repo> cad-ui
cd cad-ui
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt        # Windows
# .venv/bin/pip install -r requirements.txt          # Linux/macOS
```

## Запуск

```
.venv\Scripts\python run_ui.py
```

Без аргументов CAD UI работает как **изолированная среда**: рабочая папка = папка самого cad-ui. Клонировал → работаешь внутри неё; агенты и skills кладутся в `.claude/` и появляются во вкладке «Агенты» автоматически. При необходимости можно указать другую папку: `python run_ui.py D:\путь`. Откроется браузер на `http://127.0.0.1:8145`. Опции: `--port 9000`, `--no-browser`.

## Конфиг (опционально)

Скопируй `config.example.json` в **корень своей рабочей папки** как `workspace.config.json` и добавь свои исключения (папки/расширения, которые не показывать и не сканировать). Без конфига работают дефолтные исключения (`.git`, `node_modules`, `*_portable`, модели, архивы, видео и т.п.).

Инструмент пишет в рабочую папку только служебную папку `.cad-ui/` (избранное и, позже, поисковый индекс). Личные настройки в репозиторий cad-ui не попадают.
