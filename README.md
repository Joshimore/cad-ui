# CAD UI — Command & Agent Dashboard

Локальная веб-обёртка над рабочей папкой: дерево файлов, markdown-вьюер, недавние, избранное, реестр агентов и навыков. Строго локально: сервер слушает только `127.0.0.1`, никаких API-ключей, внешних вызовов и CDN.

Репозиторий — **изолированная среда**: это одновременно инструмент и рабочее пространство. Клонировал → запустил → работаешь внутри этой папки.

## Установка

Нужен Python 3.11+ (с pip).

```
git clone <repo> cad-ui
cd cad-ui
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt        # Windows
# .venv/bin/pip install -r requirements.txt          # Linux/macOS
```

## Запуск

Самый простой путь — двойной клик по **`start.bat`**: при первом запуске сам создаст venv и поставит зависимости, затем поднимет сервер. Вручную:

```
.venv\Scripts\python run_ui.py
```

Откроется браузер на `http://127.0.0.1:8145`. По умолчанию рабочая папка — сама папка cad-ui; при необходимости можно указать другую: `python run_ui.py D:\example-workspace`. Опции: `--port 9000`, `--no-browser`.

**Обновление системы** — двойной клик по **`update.bat`**: подтянет свежую версию из репозитория (`git pull`) и досинхронизирует зависимости; после — перезапусти `start.bat`.

**Кнопка `>_ Claude`** в шапке интерфейса открывает терминал с Claude Code в корне рабочего пространства — Claude сам читает `CLAUDE.md` и сразу понимает, как устроена система. Команда запуска настраивается в `workspace.config.json` → `claude_command` (по умолчанию `claude`).

## Разделы интерфейса

- **Центр управления** — состояние пространства: счётчики, недавние изменения.
- **Документы** — дерево файлов + markdown-вьюер (таблицы, код, относительные ссылки, картинки).
- **Недавние / Избранное** — последние изменённые и закреплённые (★) файлы.
- **Реестр: Агенты / Навыки** — появляется автоматически, когда в `.claude/agents/` или `.claude/skills/` есть файлы. Агент — `.claude/agents/<имя>.md` (frontmatter: `name`, `description`, `tools`); навык — `.claude/skills/<имя>/SKILL.md` (frontmatter: `name`, `description`).

Первый запуск у нового участника — пустой: без агентов и навыков раздел «Реестр» скрыт. Открой Claude Code в этой папке — он проведёт через настройку (см. `CLAUDE.md`).

## Конфиг (опционально)

Скопируй `config.example.json` в **корень рабочей папки** как `workspace.config.json` и добавь свои исключения (папки/расширения, которые не показывать и не сканировать). Без конфига работают дефолтные исключения (`.git`, `node_modules`, `*_portable`, модели, архивы, видео и т.п.).

Инструмент пишет в рабочую папку только служебную папку `.cad-ui/` (избранное и, позже, поисковый индекс). `workspace.config.json` и `.cad-ui/` в git не коммитятся — личное остаётся личным.
