# CAD UI — Command & Agent Dashboard

**Что это:** локальная веб-панель над рабочей папкой команды. Дерево файлов и markdown-вьюер вместо Obsidian, недавние и избранное, реестр агентов и навыков Claude Code, запуск Claude одной кнопкой. Репозиторий — **изолированная среда**: это одновременно и инструмент, и рабочее пространство — клонировал, запустил, работаешь внутри.

**Приватность:** всё строго локально. Сервер слушает только `127.0.0.1`, никаких API-ключей, внешних вызовов, CDN и облаков. Личные настройки в git не попадают.

**Версия:** `v0.1.0` — базовый функционал готов; из базового остаётся только Discord-трек.

> 🚀 **Склонировал репозиторий?** Открой **[`INSTRUCTION.md`](INSTRUCTION.md)** — пошаговая настройка среды на твоём компьютере. При первом запуске UI сам покажет подсказку с этими шагами.

## Разделы интерфейса

- **Центр управления** — состояние пространства: счётчики, недавние изменения.
- **Документы** — дерево файлов + markdown-вьюер (таблицы, код, относительные ссылки, картинки).
- **Поиск** — полнотекстовый (SQLite FTS5) с автотегами и фильтрами.
- **Недавние / Избранное** — последние изменённые и закреплённые (★) файлы.
- **Проекты** — проекты и задачи в `Working directory/`: дедлайны, статусы, цвета; календарь-таймлайн дедлайнов на дашборде.
- **Граф** — граф связей: документы, агенты, навыки; рёбра по ссылкам, `[[wiki]]` и agent↔skill.
- **Реестр: Агенты / Навыки** — появляется автоматически, когда в `.claude/agents/` или `.claude/skills/` есть файлы. Агент — `.claude/agents/<имя>.md` (frontmatter: `name`, `description`, `tools`); навык — `.claude/skills/<имя>/SKILL.md` (frontmatter: `name`, `description`).

В репозитории есть стартовый набор агентов (creator, repo-searcher, registrar) — это примеры, их можно править или удалить. Открой Claude Code в этой папке (или нажми `>_ Claude`) — он поможет настроить систему под себя (см. `CLAUDE.md`).

## Возможности (v0.1.0)

Базовый функционал готов:

- **Документы** — дерево + markdown-вьюер (GFM: таблицы, код, картинки, относительные ссылки).
- **Поиск** — полнотекстовый (SQLite FTS5), автотеги, фильтры.
- **Недавние / Избранное**.
- **Проекты и задачи** — `Working directory/`: проекты, задачи, дедлайны, статусы, цвета; календарь-таймлайн на дашборде.
- **Реестр** — авто-детект агентов и навыков Claude Code.
- **Брендированные документы** — агент `cvd-docs` + скиллы `pdf/docx/pptx/xlsx`, запуск из терминала (`>_ Claude`); шрифты бренда — в репозитории.
- **Граф связей** — узлы: документы/агенты/навыки; рёбра: ссылки, `[[wiki]]`, agent↔skill; force-раскладка на vanilla SVG.
- **Claude Launch** — `>_ Claude` открывает терминал с Claude в корне пространства.

**Остаётся из базового:** Discord-трек (уведомления о событиях задач). Дальше по плану — база знаний + CVD-сессии.
