# Шаблони (`templates/`)

Готові форми для артефактів сесії. Проза заповнюється робочою мовою (укр. за умовч.); технічні
терміни, імена інструментів, version-ідентифікатори та поля-лейбли — англійською.

| Шаблон | Коли використовується |
|--------|-----------------------|
| `session-report-template.md` | Підсумковий `REPORT.md` сесії — наратив + структура + картки + лог помилок + brief для людини. |
| `knowledge-card-template.md` | Одна підтверджена знахідка (version stamp обов'язковий; у Gold KB лише L4+). |
| `anti-pattern-template.md` | Негативний патерн: те, що НЕ спрацювало / було відхилено. Несе version stamp. |
| `error-hallucination-log-template.md` | Запис у лог помилок / галюцинацій (особливо version-галюцинації). |
| `session-telemetry-template.md` | Per-session телеметрія (tokens / tool-uses / duration), яку веде оркестратор. |

Примітка: `reporter` **не пише файли** — він повертає готовий текст, а **оркестратор зберігає**
`REPORT.md` і застосовує оновлення KB (так влаштовано harness; див. `../CLAUDE.md` §6).
